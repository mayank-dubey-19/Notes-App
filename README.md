# 📝 Notes App

A simple and user-friendly **Notes App** built using **HTML, CSS, and JavaScript**. It allows users to create, search, edit, and delete notes easily through a clean and responsive interface.

### ✨ Features

* ➕ Create new notes
* 🔍 Search notes quickly
* ✏️ Edit existing notes
* 🗑️ Delete notes
* 💾 Save notes using Local Storage
* 📱 Responsive and easy-to-use UI

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

This project was created to practice **DOM manipulation, JavaScript events, Local Storage, and search functionality**.
